# SolidityOcta

SolidityOcta is a High-Performance Distributed Engine for Smart Contract Management and Orchestration at the Core.

With SolidityOcta, you get a lightweight tool that stays out of your way.

**What you get**

- SolidityOcta is a High-Performance Distributed
- Engine for Smart Contract Management
- and Orchestration at the Core

## Key Features

- and Orchestration at the Core

## Technology Stack

- typescript
- typescript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/SolidityOcta.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

SolidityOcta is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
